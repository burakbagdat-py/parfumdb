# Parfüm Çarkı

Parfüm koleksiyonu, haftalık rastgele parfüm planı, kategori çarkı ve günlük bildirimler.

- `docs/` – uygulamanın ekranları (GitHub Pages'ten yayınlanır, her açılışta güncel hali yüklenir)
- `docs/data/` – dünya parfüm kataloğu ve Boyner marka listesi (`scripts/build_catalog.py` üretir, haftalık güncellenir)
- `android/` – bildirimleri gönderen Android kabuğu (GitHub Actions derler, Releases'a koyar)
